# Repository audit and implementation plan

Audit of the original repository (spam classifier, Streamlit UI, notebooks) and what was done about each item.

## Findings

| # | Priority | Finding | Resolution |
|---|----------|---------|------------|
| 1 | High | **Possible train/test leakage.** `load_and_clean` drops duplicates *before* cleaning; 163 duplicates remain after cleaning, and 53 of 1,139 test rows also occur in the training set. | Kept `train.py`/split unchanged for compatibility; `train_compare.py` evaluates on a leak-free test set and also reproduces the original split numbers. |
| 2 | High | **Model loaded via pickle (`joblib`) with no integrity check.** | SHA-256 manifest verified at load (`STRICT_MODEL_INTEGRITY=1` refuses on mismatch); README warns to load only self-trained models. |
| 3 | High | **Devcontainer disabled Streamlit XSRF and CORS protection.** | Removed the flags; `.streamlit/config.toml` keeps protections on. |
| 4 | Medium | **Probabilities shown as "confidence" were uncalibrated NB scores.** | Platt scaling fitted on out-of-fold training predictions; Brier/ECE reported. |
| 5 | Medium | `.env` and `logs/app.log` committed (log contained local Windows paths). | `.env` replaced by `.env.example`; `.env` and `logs/` git-ignored; log redaction filter added. |
| 6 | Medium | App showed raw exception text (`Prediction failed: {error}`); no input size limit; model reloaded on every click. | Friendly errors (details logged without content), input limits, cached engine. |
| 7 | Medium | README contained unresolved merge-conflict markers; it referenced `reports/` while the artefacts were in `notebooks/reports/` (with `(2)` duplicates). | README rewritten; `reports/` now generated by `train_compare.py`. Old notebook outputs were left untouched. |
| 8 | Low | Google Fonts `@import` leaked page loads to a third party; `sys.path` hacks. | System font stack; single bootstrap in `app.py`. |
| 9 | Low | `train.py` has no versioning, seed recording, or data hash; `import json` inside a function. | `train_compare.py` records data SHA-256, seed, library versions, params and a deterministic version id. `train.py` additionally writes the manifest. |
| 10 | Info | Dataset has spam/ham labels only (no phishing labels, mostly corporate-style ham). | Phishing/URL/sender/header features are explicitly labelled as heuristics; never described as trained or benchmarked. |

## Plan and status

1. Audit and plan - done.
2. Core package `src/mailguard/` (parsing, urls, sender, headers, phishing, scoring, explain, calibration, registry, history, reports, external) - done, unit-tested.
3. Reproducible training/evaluation (`src/train_compare.py`) - done.
4. Streamlit dashboard (7 pages, native light/dark themes) - done, browser-checked in both themes and on a phone viewport.
5. Tests (65), docs, requirements - done.
